## 1. What This Is

An **AutoCAD 2027 .NET plugin** (C#, net10.0-windows, WinForms) that inserts steel column blocks for MS (mild-steel) parking towers, positioned by tower-combination CTC data. One command — `RR-MS-Tower-Stage` — opens a **two-page wizard** (page 1: tower config + stages + "Previous use", `Next >`; page 2: pick 2 steel materials + assign each numbered Line — see §5b — `< Back`/`Insert`), then inserts a **FRONT ELEVATION**, a **REAR ELEVATION**, one **LINE N ELEVATION** per numbered column (side views, spaced by Car Length CTC), and **PLAN views** (top-down column footprints, stacked in rows of 2 below the elevations — 4 rows/8 plans normally, growing by 2 plans per extra material-change phase the PALLET/GIRDER PLAN row replicates for, see §7) at a user-picked point. All units are **mm**.
